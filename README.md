# Jiu-Admin — Carlson Gracie School Admin Panel

Admin panel for managing students, belts, graduations, lessons, frequencies, and medical clearances for a Carlson Gracie Jiu-Jitsu school. Built with **Angular 19**, **PrimeNG 19 LTS**, and **Keycloak** authentication.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Angular 19 (standalone + signals) |
| UI Library | PrimeNG 19 LTS + PrimeIcons |
| Theme | `@primeuix/themes` Aura preset |
| Authentication | Keycloak (Authorization Code + PKCE) |
| HTTP | Angular `HttpClient` + keycloak-angular bearer interceptor |
| API generation | OpenAPI Generator (typescript-angular) |

---

## Prerequisites

- Node.js 20+
- Angular CLI 19: `npm install -g @angular/cli`
- A running [Keycloak](https://www.keycloak.org/) instance (see [Keycloak setup](#keycloak-setup))
- Main backend running at `http://localhost:8080`
- Face recognition backend running at `http://localhost:8003` (optional)

---

## Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm start
# → http://localhost:4200
```

The app will redirect unauthenticated users to Keycloak automatically.

## Available Scripts

```bash
npm start              # Dev server at http://localhost:4200
npm run build          # Production build → dist/
npm test               # Unit tests via Karma

npm run generate:all   # Both APIs
```

> ⚠️ **Never edit files inside `src/app/generated_services/` manually.** They are fully regenerated by the OpenAPI generator.

## Environment Configuration

Edit `src/app/enviroments/environment.ts` for local development:

```ts
export const environment = {
  production: false,
  server: 'http://localhost:8080',
  face_api: 'http://localhost:8003/api/v1',
  keycloak: {
    url: 'http://localhost:8180',
    realm: 'bjjclutch',
    clientId: 'jiu-admin',
  },
};
```

Production values (`environment.prod.ts`):
- `server`: `https://api.bjjclutch.com.br`
- `face_api`: `https://face-recognition.bjjclutch.com.br`
- `keycloak.url`: `https://auth.bjjclutch.com.br`

> Note: the `enviroments/` directory name has a typo (missing 'n') — do not rename it as it is referenced throughout the codebase.

## Keycloak Setup

1. Start Keycloak (Docker example):
   ```bash
   docker run -p 8180:8080 \
     -e KEYCLOAK_ADMIN=admin \
     -e KEYCLOAK_ADMIN_PASSWORD=admin \
     quay.io/keycloak/keycloak:latest start-dev
   ```
2. Create realm: `bjjclutch`
3. Create client: `jiu-admin` (type: Public, PKCE enabled)
4. Set valid redirect URIs: `http://localhost:4200/*`
5. Set web origins: `http://localhost:4200`
6. Assign roles `manage-realm` and `manage-users` to admin users (required by `AuthGuard`)

## Architecture Decisions

### Authentication
Keycloak Authorization Code + PKCE flow via `keycloak-angular@19`. The library handles:
- Token storage
- Auto-refresh via `withAutoRefreshToken()`
- Bearer token attachment to HTTP requests

`AuthGuard` extends `createAuthGuard()` and checks for `manage-realm` + `manage-users` realm roles.

### State Management
Component state uses Angular 19 **signals** (`signal()`, `computed()`, `effect()`).
Services use signals for shared state (`SubnavService.title()`).
No external state library is used.

### UI Components
All UI is built with **PrimeNG 19 LTS**:
- Tables → `p-table`
- Modals → `p-dialog`
- Forms → `p-inputtext`, `p-select`, `p-button`
- Pagination → `p-paginator` (wrapped in `PaginationComponent`)
- Notifications → `p-toast` + `MessageService` (wrapped in `NotificationService`)

### Change Detection
All components use `ChangeDetectionStrategy.OnPush`. Signals integrate with OnPush automatically.

## Notifications

Use `NotificationService` (never `alert()` or raw `console`):

```ts
private readonly notify = inject(NotificationService);

this.notify.showSuccess('Título', 'Operação realizada com sucesso.');
this.notify.showError('Título', 'Ocorreu um erro.');
this.notify.showWarning('Título', 'Atenção.');
this.notify.showInfo('Título', 'Informação.');
```

All user-facing text is in **Brazilian Portuguese**.
